Как установить Zyntra Launcher на Mac

  1. Скачайте ZyntraLauncher-macOS.dmg.
  2. Откройте файл двойным кликом — появится окно с иконкой лаунчера и папкой «Программы».
  3. Перетащите Zyntra Launcher на папку «Программы».
  4. Откройте «Программы» и запустите лаунчер (первый раз — как описано ниже).

Что делать, если macOS не даёт открыть лаунчер?

Это нормально для первого запуска: у лаунчера нет платной подписи Apple, поэтому macOS не знает разработчика. Разрешить запуск нужно один раз.

macOS 14 Sonoma и старше

  1. В «Программах» нажмите на Zyntra Launcher правой кнопкой (или с зажатым Control).
  2. Выберите «Открыть», затем ещё раз «Открыть» в окне предупреждения.

macOS 15 Sequoia и новее

  1. Запустите лаунчер обычным двойным кликом и закройте окно с предупреждением.
  2. Откройте Системные настройки → Конфиденциальность и безопасность.
  3. Внизу, рядом с сообщением о Zyntra Launcher, нажмите «Всё равно открыть» и подтвердите паролем.

Дальше лаунчер открывается как любое приложение.

Какие версии Minecraft работают на M1?

Все. Версии 1.19 и новее запускаются нативно на Apple Silicon — быстро и без нагрева. Версии до 1.19 (например 1.8.9, 1.12.2, 1.16.5) запускаются через Rosetta: у них есть библиотеки только для Intel. Так же делает официальный лаунчер Mojang.

Rosetta macOS предложит установить сама при первом запуске старой версии — согласитесь. Нужная Java (для Apple Silicon или для Intel) скачивается автоматически.

Где лаунчер хранит игру на Mac?

ЧтоПапка
Версии, миры, моды~/Library/Application Support/Zyntra Launcher/minecraft
Настройки лаунчера~/Library/Application Support/Zyntra Launcher/zyntra.json
Версии из официального лаунчера и TLauncher~/Library/Application Support/minecraft — Zyntra показывает их сам

Чтобы открыть папку Library в Finder: меню «Переход» → «Переход к папке…» и вставьте путь.

Работает ли Horizon на Mac?

Да. Horizon и Horizon OptiFine скачиваются в версии для Apple Silicon. Для зума в Horizon OptiFine macOS может попросить разрешение «Мониторинг ввода» для Zyntra Launcher — без него лаунчер не видит, что вы зажали клавишу зума.

Есть ли версия для Intel-Mac?

Пока нет: сборка только для Apple Silicon (M1 и новее). Версия для Intel-Mac в планах.

Нужно ли ставить Java на Mac?

Нет. Лаунчер сам скачивает официальную Java от Mojang нужной версии.

Сколько памяти выделять Minecraft на MacBook?

Лаунчер выбирает сам: половину оперативной памяти, от 2 до 8 ГБ. На MacBook Air с 8 ГБ это 4 ГБ — для обычной игры и небольших сборок модов достаточно.
