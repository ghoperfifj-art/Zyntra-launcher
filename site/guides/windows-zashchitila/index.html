«Система Windows защитила ваш компьютер» — что делать

Окно «Система Windows защитила ваш компьютер» — это фильтр SmartScreen. Он появляется у программ без платной цифровой подписи. Чтобы установить Zyntra Launcher, нажмите «Подробнее», затем «Выполнить в любом случае».

Обновлено 3 ноября 2026

Как запустить установщик

  1. Запустите ZyntraSetup-Windows.exe.
  2. В синем окне нажмите ссылку «Подробнее».
  3. Появится кнопка «Выполнить в любом случае» — нажмите её.
  4. Установщик откроется. Права администратора не нужны: лаунчер ставится для текущего пользователя.

Почему Windows показывает это окно?

SmartScreen предупреждает о любой программе, которую скачали ещё мало людей и у которой нет платного сертификата подписи кода. Это не значит, что в файле вирус — так Windows реагирует на большинство небольших бесплатных программ.

Как убедиться, что файл безопасен?

  • Скачивайте лаунчер только с этого сайта или со страницы релизов на GitHub.
  • Исходный код лаунчера опубликован на GitHub, а установщик собирается из него автоматически на серверах GitHub.
  • Файл можно проверить на VirusTotal перед запуском.
Кнопки «Выполнить в любом случае» нет

Значит, в Windows включён строгий режим (например, на школьном или рабочем компьютере). Его может отключить только администратор компьютера.

Антивирус удалил установщик

Некоторые антивирусы так реагируют на новые неподписанные программы. Проверьте файл на VirusTotal и, если всё чисто, добавьте его в исключения антивируса.
