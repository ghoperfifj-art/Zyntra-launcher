FAQ

Is it free?

Yes, completely. No ads, subscriptions or paid features. The code is open source under the MIT license on GitHub.

Do I need a Minecraft license?

No, you can play with any nickname using an offline profile. Servers that check licenses will not let such a profile in; regular servers and single player work fine.

Why do Windows or macOS warn me on first launch?

The launcher has no paid code-signing certificate from Microsoft or Apple, so the system does not know the developer. Allow it once and it opens like any other app afterwards.

Does it pick up my TLauncher versions?

Yes. Zyntra finds the versions and modpacks in the TLauncher folder and launches them with all their mods.

What is Horizon?

An unofficial project that rewrote Minecraft Java Edition 26.3 in Rust. It runs noticeably better on weak hardware. Zyntra downloads it for you and adds OptiFine-style settings, zoom and mods.

Does it work on Intel Macs or Linux?

For now the Mac build is for Apple Silicon only (M1 and newer). Intel Mac and Linux versions are planned.
